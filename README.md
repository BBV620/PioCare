# PioCare

**RO** — Panou modern de întreținere pentru Windows, independent:

- întreținerea generală a sistemului de operare;
- curățarea cheilor de registru rămase de la aplicațiile dezinstalate;
- detectarea dependențelor dintre componentele și serviciile Windows, ca să rămână pornit doar ce îi folosește utilizatorului, iar restul să poată fi oprit;
- o politică de firewall orientată spre siguranța utilizatorului.

Scopul: calculatorul să revină la performanța lui reală, cu navigare mai sigură pe internet.

**EN** — A modern, standalone maintenance dashboard for Windows:

- general operating system maintenance;
- cleanup of leftover registry keys from uninstalled apps;
- dependency detection between Windows components and services, keeping on only what the user needs;
- a firewall policy focused on user safety.

Goal: bring the PC back to its real performance, with safer browsing.
